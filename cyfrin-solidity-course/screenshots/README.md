# 📸 Screenshots

This folder contains screenshots demonstrating course progress and completion on Cyfrin Updraft.

## What to Add Here

Place your progress screenshots in this folder:

| File Name | Description |
|-----------|-------------|
| `01-simple-storage-complete.png` | Module 1 (Simple Storage) — 16/16 lessons done |
| `02-storage-factory-complete.png` | Module 2 (Storage Factory) — 10/10 lessons done |
| `03-fund-me-complete.png` | Module 3 (Fund Me) — 29/29 lessons done |
| `04-ai-prompting-complete.png` | Module 4 (AI Prompting) — 7/7 lessons done |
| `05-course-100-percent.png` | Full course at 100% progress |

## Note on Certificates
The **official course certificates** are stored in the [`/certificates`](../certificates/) folder:
- `solidity-smart-contract-development-certificate.png` — Solidity 101 badge ✅
- `blockchain-basics-certificate.png` — Blockchain Basics certificate ✅

## How to Take Screenshots
1. Log in to [updraft.cyfrin.io](https://updraft.cyfrin.io)
2. Open your course dashboard
3. Navigate to each completed module
4. Screenshot the progress bar showing completion
5. Save to this folder with the naming convention above
